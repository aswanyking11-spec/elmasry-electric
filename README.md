# ⚡ ELMASRY ELECTRIC — أدوات ومستلزمات الكهرباء

متجر إلكتروني عربي كامل (RTL) للأدوات الكهربائية مع لوحة تحكم إدارية وطرق دفع عند الاستلام، جاهز للنشر على Vercel مع قاعدة بيانات Turso السحابية.

## ✨ المميزات

- 🛍️ متجر كامل: تصنيفات، منتجات، باقات، سلة، وطلبات
- 🔐 لوحة إدارة محمية برمز سري (منتجات / طلبات / باقات / تصنيفات / إعدادات)
- ☁️ إعداد ذاتي لقاعدة البيانات السحابية بزر واحد من لوحة الإدارة
- 📱 تطبيق PWA قابل للتثبيت + ملف APK جاهز
- 💾 قاعدة بيانات: SQLite محلياً أو Turso (libSQL) على السحابة — اختيار تلقائي

## 🚀 التشغيل المحلي

```bash
npm install        # أو bun install
npm run db:push    # إنشاء قاعدة البيانات المحلية
npm run dev        # التشغيل على المنفذ 3000
```

ثم افتح `http://localhost:3000` — سيتم تعبئة بيانات تجريبية تلقائياً عند أول تشغيل للإدارة.

## ☁️ النشر على Vercel + Turso

1. أنشئي قاعدة بيانات مجانية على [turso.tech](https://turso.tech) واحصلي على `DATABASE_URL` و `DATABASE_AUTH_TOKEN`
2. استوردي المشروع على [vercel.com](https://vercel.com) وأضيفي متغيري البيئة أعلاه
3. بعد النشر: افتحي موقعك ← الإدارة (الرمز الافتراضي `1234`) ← الإعدادات ← زر **«تجهيز قاعدة البيانات السحابية»**
4. غيّري رمز الإدارة فوراً من الإعدادات

## 🗂️ البنية

```
src/app/page.tsx      # واجهة المتجر + لوحة الإدارة (تطبيق بصفحة واحدة)
src/app/api/          # مسارات API (منتجات، طلبات، سلة، إعدادات، إعداد ذاتي)
src/lib/db.ts         # عميل Prisma (محلي أو Turso تلقائياً)
src/lib/db-setup.ts   # إنشاء الجداول والتعبئة الأولية
prisma/               # مخطط قاعدة البيانات + سكربت التعبئة
public/               # أيقونات PWA وملف APK
```

## 🔑 متغيرات البيئة

| المتغير | الاستخدام |
|---|---|
| `DATABASE_URL` | `libsql://...` للسحابة أو `file:../db/custom.db` محلياً |
| `DATABASE_AUTH_TOKEN` | رمز Turso (سحابي فقط) |
